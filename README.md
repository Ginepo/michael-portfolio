# michael-portfolio

A single-page personal portfolio built with HTML, CSS, and JavaScript.



\## Features

\- About Me, Skills, and Contact sections

\- Profile photo with alternative text

\- Light and dark theme toggle

\- Demo contact form with a confirmation message

\- Responsive layout for smaller screens



\## How to Run

Download or clone this repository and open index.html in a browser.

Keep all files in the same folder.



\## Technologies

HTML, CSS, and JavaScript.



The contact form is a demonstration and does not send messages.
